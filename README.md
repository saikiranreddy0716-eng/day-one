# Student Data Processor

A beginner Python command-line project that accepts
student names and marks, validates input, and displays
a formatted student report.

## Requirements
- Python 3
- No external packages required

## Setup
1. Open the project folder in VS Code.
2. Create a virtual environment:
   python -m venv .venv
3. Activate it in PowerShell:
   .\.venv\Scripts\Activate.ps1

## Run
python app.py

## Features
- Validates student names and marks.
- Calculates pass/fail results.
- Displays total students and class average.
- Uses functions, loops, lists, dictionaries,
  conditions, and list comprehensions.
